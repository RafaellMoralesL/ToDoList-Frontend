# ToDoList  
Este repositorio contiene un proyecto para crear una ToDoList o una Lista de cosas por hacer.

## Dependencias usadas  
Para este proyecto se utiliza
- bootstrap
- react
- react-bootstrap
- react-dom
- -sass

## Requisitos  
Para poder comenzar este proyecto se necesita:

- [Node.js] (https://nodejs.org/en/download) Para este repositorio se usó la version 24.13.1

## Instrucciones  
Clonar el repositorio: 

```bash
git clone https://github.com/RafaellMoralesL/ToDoList-Frontend.git
```  
Instalar las dependencias  
```
npm install
```
Para iniciar el proyecto  
```
npm run dev
```
